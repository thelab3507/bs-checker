How to read this

Calibration asks whether "90% sure" means right nine times in ten. Overconfident means the model claims more than it delivers; underconfident the reverse.

The verdict comes from the gap, the model's average confidence minus its accuracy, and its 95% interval. An interval wholly above 0 is overconfident, wholly below 0 underconfident, and one that spans 0 is honest. There is no size cut-off, so the size is printed with every label. A run with under 100 answers or under 30 independent groups gets no verdict.

Bands. Headline ECE uses {{.BandScheme}}. The charts use {{.FineBandScheme}}, because a model that is nearly always at 99.99% falls into a single headline band.

Groups. Questions about one passage are not independent, so intervals resample whole groups. Grouping by set: {{range .ClusterBy}}{{.Key}} by {{.Value}}; {{end}}

Caveats. ECE can never be below 0, so its own interval leans high when there are few answers; use the verdict's interval rather than the bare ECE. A correction rescales confidence and never changes which answer a model gives. d1's own probabilities are already scaled by its vendor, so its correction is a second scaling.
